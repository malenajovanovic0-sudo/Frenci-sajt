# Frenči sajt

Sajt za Frenči — kroasančići i kafica, Makedonska 24, Beograd.

Statičan sajt: jedan `index.html` (Početna, Meni, Ketering i dostava, Kontakt preko `#hash`), mobilna verzija + desktop od 900 px.

- `img/`, `o/` — fotografije i ilustracije (izvor: Figma „Frenči sajt")
- `CabinetGrotesk-Variable.ttf` — brend font
- `frenci-logo.svg` — logo

Lokalni pregled: otvori `index.html` u browseru ili `python3 -m http.server`.
